# Offer Helper v0.3.0 · Windows 桌面版

本次将本地 Web 工作台封装为 Windows x64 桌面软件。软件自带 Python 和界面运行环境，无需另装 Python、浏览器或 WebView2。

## 更新内容

- 独立桌面窗口，后台随软件启动和退出。
- 安装程序、桌面快捷方式、窗口及页面左上角使用猫咪照片图标。
- 保留 70% 不透明度的置顶回答悬浮窗、全文自动适配、Windows 采集排除及共享画面预览。
- 共享预览增加桌面选屏与采集授权处理。
- 增加语音模型下载、已有模型目录选择和数据目录入口。
- 配置、模型和日志存放于 `%LOCALAPPDATA%\OfferHelper`。
- 保留手机配对、回答模型配置、简历预读和原有 Web 启动方式。

## 下载与使用

- **OfferHelper-Setup-0.3.0-x64.exe**：推荐。安装到当前用户目录，创建桌面快捷方式，并提供 Windows 应用列表中的卸载入口。
- **OfferHelper-0.3.0-windows-x64.zip**：便携版。解压后运行 `OfferHelper.exe`，请保留同目录的 `_internal` 文件夹。
- **SHA256SUMS.txt**：安装包和便携版的 SHA-256 校验值。

首次使用请配置回答模型，并在“语音模型”菜单选择或下载识别模型。本地 Ollama 回答模型需另外安装。发布包不包含模型权重、个人配置或密钥。

旧版迁移方式见安装目录中的《使用说明.txt》。卸载会保留个人配置和下载模型。
